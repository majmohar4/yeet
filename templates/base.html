How yeet works

Upload

  • Drop files or a whole folder onto the upload area, or tap it to pick files.
  • On a phone, Photos & videos opens your gallery; Paste saves text or an image to the public clipboard.
  • When an upload finishes, its link is copied for you. On phones you get a Share button instead.

Big files

Uploads are sent in {{ (chunk_mb|default(16)) }} MB pieces, several at a time. A dropped connection only retries the piece that failed, and if you lose the page you can pick the same file again to continue where it stopped. Keep the tab open until the row says Ready.

Downloads

Opening a link shows a page with a preview and a download button. Downloads can be paused and resumed by your browser, and big files are fetched in pieces where the browser supports it.

Expiry

Every file deletes itself after the time you pick. Expired files are gone for good after a further 24 hours.

Password

Recipients need the password to preview or download. Only a bcrypt hash is stored.

Single download

The file is deleted from the server the moment someone downloads it. Chat-app link previews don't count, so pasting the link into a chat is safe.

Folders

A folder becomes one link with a file list and a Download all button that zips everything on the fly.

Public clipboard

Pasted text and images are visible to every visitor. Don't paste anything private there.

Any HTTP client works. With curl:

curl -F f=@notes.txt https://YOUR-HOST/raw            # prints the link
curl -F f=@photo.jpg -F burn=1 https://YOUR-HOST/raw  # single download
curl -OJ https://YOUR-HOST/f/<id>                      # download

For big files use the bundled yeet script — it uploads in pieces and resumes downloads:

YEET_URL=https://YOUR-HOST yeet upload video.mov --expiry 168
yeet download https://YOUR-HOST/f/<id>

yeet is a small open-source file drop: FastAPI, SQLite and ClamAV in one container. No accounts, no analytics, no third-party scripts. Every upload is virus-scanned before it is published.
